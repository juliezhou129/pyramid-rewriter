# Pyramid Rewriter

运用金字塔原理重构逻辑、提炼洞察、精炼表达的 Codex Skill。

它可将结构松散、信息堆叠或结论不强的原始材料，重构为结论先行、论据有序、表达专业且符合具体载体的内容。支持策略方案、管理报告、PPT 文字稿、邮件、演讲稿、说明性文档、通知和即时沟通。

## 特点

- 结论先行，标题必须包含真实判断。
- 上下层形成支撑关系，同层论据同类且有序。
- 长文通过单轮单问的需求访谈确认场景、受众、目标、格式和风格。
- 支持直接改写、轻量处理和标准确认三种通道；明确“不要提问／别问了”时，轻量处理后同一轮直接成稿。
- 标准方向确认固定按 A—F 六个独立板块输出，提交前检查完整性与顺序。
- 保留原始事实、数据、因果边界和用户立场。
- 针对报告、PPT、邮件、演讲稿和短消息提供不同输出骨架。

## 仓库结构

```text
SKILL.md
references/
evals/
```

`SKILL.md` 包含主流程和核心规则，`references/` 保存按需加载的方法、确认模式、输出格式与质量量表，`evals/` 包含15个基础行为评测场景及测试附件，另有 `regression-20261111.json` 保存确认分流、限定保真和连续访谈的定向回归场景。

## 安装

将仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/juliezhou129/pyramid-rewriter.git ~/.codex/skills/pyramid-rewriter
```

重启或刷新 Codex 后即可使用。
